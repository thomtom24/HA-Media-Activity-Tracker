# Audit remediation

This candidate consolidates changes in one PR. The audit is not a certification. Review CI and test on real HA before release. Remaining work requiring verification: Marketplace installation/update, genuine device data and screenshots, latest Core runtime tests, full disk-failure recovery and Pi performance measurement. Known limitations: old history lacks explicit coverage and tracking-mode metadata; new history records observed/unavailable source time; current mode changes mark aggregate history mixed. Existing data is not reclassified. Offline JSON export/restore is included; no live destructive import UI. App settings remain comma-separated; entity rename resolution for source/conditions is supported, new/saved card configurations carry stable tracker IDs; legacy unsaved configurations still need re-selection after rename. Timezone edge cases, event coalescing, restricted users, keyboard navigation, chart scaling and translation need further testing/implementation. Direct tracker-sensor dependencies are rejected conservatively; indirect template/automation cycles are not detected. No external APIs or telemetry.
