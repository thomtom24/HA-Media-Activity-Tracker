# Security policy

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/thomtom24/HA-Media-Activity-Tracker/security/advisories/new), if available, or contact the project owner via [website](https://www.tombale.me). Do not include real household activity, backups, credentials or access tokens in public issues. Only the latest release is actively supported; this is a volunteer project without a guaranteed response time.
